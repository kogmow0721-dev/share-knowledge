隱私權政策

最後更新：2026 年 11 月 12 日

這個應用程式做什麼

「知識共享」是頻道經營者自用的上傳工具，透過 Google OAuth 取得授權後，使用 YouTube Data API 將教學影片、縮圖與字幕上傳到經營者自己的 YouTube 頻道，並讀取該頻道的基本資訊（名稱、訂閱數、影片數）。

我們存取哪些資料

  • 授權帳號所擁有的 YouTube 頻道基本資訊。
  • 上傳影片、縮圖與字幕所需的權限。

我們不會存取其他使用者的資料，也不會讀取私人訊息、聯絡人或觀看紀錄。

資料如何儲存

授權權杖只儲存在經營者自己的電腦上，不會上傳到任何伺服器，也不會提供、出售或分享給第三方。

Google API 服務使用者資料政策

本應用程式對 Google API 所取得資訊的使用與傳輸，遵守 Google API 服務使用者資料政策，包括有限使用要求。本應用程式使用 YouTube API 服務，使用者也受 YouTube 服務條款與 Google 隱私權政策規範。

撤銷授權

隨時可以到 Google 帳戶的第三方存取權頁面撤銷本應用程式的權限。

聯絡方式

有任何問題，請透過 GitHub Issues 與我們聯絡。
