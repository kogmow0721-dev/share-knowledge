Day 4

Claude Code：請 Claude 直接進你的電腦

報稅前一個星期，水電師傅的太太阿芬打開發票的資料夾，兩百四十張，全是手機拍的。每一張都要打開、看金額、改檔名、搬資料夾。聊天版的 Claude 看得懂發票，可是碰不到她電腦裡的檔案。今天換 Claude Code 登場，它直接進到這個資料夾，自己動手。先說清楚：今天第一次要用到付費版。先不用馬上付錢，看完這一課，你就知道自己需不需要。不會的，就問 Claude。

看不到影片？到 YouTube 觀看。每一段的一分鐘短片在 AI 實戰短片播放清單。

先下載示範檔案

影片裡示範用的是 40 張發票和收據，有手機拍的照片，也有 PDF。店名、統一編號、發票號碼全部是虛構的。裡面故意放了幾張容易出錯的：反光看不清金額的、同一張拍了兩次的、一張照片拍到兩張發票的、手寫的收據。

ZIP示範用的 40 張發票C｜解壓縮之後，會有一個「發票」資料夾

A｜它跟聊天版哪裡不一樣

聊天版你問它答。檔案要你一個一個傳上去，做好的東西要你自己下載、自己改檔名。
Claude Code待在你指定的資料夾裡，自己開檔案、改檔案、跑程式，一次做完很多步。
同一個 Claude頭腦一樣，只是多了一雙手。
Claude Code 要付費方案才能用
它要 Pro 以上的方案，每月 20 美元起（一次付一年是 200 美元）。免費方案不包含 Claude Code，官方也沒有試用。價格請以 claude.com/pricing 當時的頁面為準。需不需要付這筆錢，請先看完 D 段。

B｜打開它，做第一件事

Claude Code 有兩個入口，裡面是同一個 Claude。第一次用，建議從電腦版 App 開始。

入口一：電腦版 App 的 Code 分頁

  1. 打開 Day 0 裝好的 Claude 電腦版，登入付費的帳號，點最上面的 Code。你不用另外安裝任何東西。
  2. 輸入框下面有一排選項，點 選擇資料夾，選你要交給它的那一個資料夾。
  3. 它會問 要信任此工作區嗎？ 按 信任工作區。之後它只會讀寫這一個資料夾。
  4. 同一排的最右邊是權限選單，有 自動、手動、接受編輯、規劃 四個。新手先停在 手動，它要變更任何東西之前，一律先問你。
  5. 第一句話，先叫它只看不動手：
看一下這個資料夾，先不要動任何檔案，告訴我裡面有什麼。

實測時它回報資料夾裡有 40 個檔案，4 個 PDF、36 張圖片，最後說「我會等你說了再動手」。

資料夾放在「文件」裡，Mac 會多問一次
如果你選的資料夾在「文件」「桌面」或「下載項目」裡，macOS 會跳出一個系統視窗，問要不要讓 Claude 存取那個位置。要不要允許由你決定。不想開的話，把要整理的資料夾搬到別的地方再選。

入口二：終端機

終端機是一個只能打字的視窗。它看起來像電影裡駭客用的畫面，其實沒有想像中困難，只是另一種呈現的介面：App 用滑鼠點，終端機用打字，做的事一樣。兩個系統的步驟不太一樣，選你的電腦：

macOS

  1. 按 Command + 空白鍵，輸入「終端機」（或 Terminal），按 Enter。
  2. 貼上這一行，按 Enter，等它跑完：
    curl -fsSL https://claude.ai/install.sh | bash
  3. 輸入 claude，按 Enter。第一次會打開瀏覽器請你登入。
  4. 如果出現 command not found: claude，把整段訊息截圖，丟給聊天版的 Claude，請它告訴你怎麼修。

系統需求：macOS 13 以上，記憶體 4 GB 以上。

Windows

  1. 按 Windows 鍵 + X，選「終端機」或「Windows PowerShell」。
  2. 貼上這一行，按 Enter，等它跑完：
    irm https://claude.ai/install.ps1 | iex
  3. 輸入 claude，按 Enter。第一次會打開瀏覽器請你登入。
  4. 如果出現 'claude' is not recognized，把整段訊息截圖，丟給聊天版的 Claude，請它告訴你怎麼修。

系統需求：Windows 10（1809）以上，記憶體 4 GB 以上。官方建議另外安裝 Git for Windows，沒有裝也能用。

要讓它進到某一個資料夾，先輸入 cd 加一個空格，把資料夾拖進終端機的視窗，按 Enter，再輸入 claude。

C｜實戰：整理一整個資料夾的發票

動手之前，先做兩件事

  • 把資料夾複製一份。萬一弄亂了，原本的都在。
  • 先拿一小批試。影片裡先拿 40 張，試順了再做全部。

步驟

  1. 把權限選單切到 規劃。這個模式下，它只會先給你一份計畫，不會動手。
  2. 把要求一次講清楚：
這些是我們 9 月和 10 月的進貨發票和收據。請幫我整理：每個檔案改名成「日期_廠商_金額」，按月份分到「9月」「10月」兩個資料夾，再做一張 Excel 總表給記帳士（日期、廠商、賣方統編、發票號碼、金額、檔名）。金額或日期看不清楚的不要猜，同一張拍了兩次的不要算兩次，這些另外列在「請你確認.txt」。
  1. 它會先抽幾張來看，然後交出一份計畫，畫面右邊會開出「計畫」面板。不滿意就按 修訂…，用講的請它改；滿意了才按 接受。
  2. 它開始讀每一張發票。讀完會先回報有問題的檔案，並且停下來問你要不要照這份對照表動手。到這一步，一個檔案都還沒有被動過。
  3. 你說可以，它才開始改名、分資料夾、做總表。

實測的結果

項目結果
改好檔名、分好資料夾35 個檔案。「9月」20 個，「10月」15 個
發票總表.xlsx35 列，欄位是日期、廠商、賣方統編、發票號碼、金額、檔名
留在原地等你確認5 個檔案：金額反光看不清的 2 張、同一張拍了兩次的 2 張、一張照片拍到兩張發票的 1 張
它自己多做的事動手前先記下每個檔案的指紋，做完再比對，確認檔案只是改名搬移、內容沒有變
檔案很多的時候，分批做
讀圖片很吃用量。兩百多張一次做，很可能碰到方案的用量上限，要等幾個小時才能繼續。比較穩的做法是一次做一個月的量，做完一批再做下一批。

D｜你需要它嗎？

免費版就夠平常只是問問題、寫文字、整理一兩個檔案。Day 0 到 Day 3 的做法都不用付錢。
可以考慮付費檔案很多、步驟很多、每個月都要做一次，像今天的發票。
想做出工具後面幾課會做能上線的小工具，那也會用到它。

拿不定主意，可以先問聊天版的 Claude：

我每個月都要……，檔案大概有……個。這件事用 Claude Code 做得到嗎？需要付費方案嗎？

讓它動手，守住三件事

  • 先備份。動手之前，把資料夾複製一份。
  • 只給它一個資料夾。不要把整台電腦交給它。
  • 它問你的時候，看清楚再按。看不懂它在問什麼，就請它用白話再講一次。

App 裡的另一個選項：Cowork

你在 App 裡會看到另一個選項叫 Cowork。它同樣是付費方案的功能，也能讀寫你電腦裡的資料夾。簡單分：Cowork 適合把一件事交辦出去，Claude Code 適合做出工具。這門課後面用的是 Claude Code。

今天的作業

  • 沒有付費的人：想一件檔案很多、每個月都要做的事，問聊天版的 Claude「這件事用 Claude Code 做得到嗎？」
  • 有付費的人：複製一個資料夾，打開 Code 分頁，先叫它只看不動手。
  • 過程中卡住了，就截圖問 Claude。
