Day 1

辦公室實戰：亂七八糟的表，變成報表和簡報

今天直接上工作現場，用四種工作示範：整理表格、做報表、做簡報、寫會議記錄。每一步免費版都做得到。不是這四種工作也沒關係，做法都一樣。整堂課還是那一句話：不會的，就問 Claude。

看不到影片？到 YouTube 觀看。每一段的一分鐘短片在 AI 實戰短片播放清單。

先下載示範檔案

影片裡用的四個檔案都在這裡，可以下載下來一起做。資料都是虛構的。

XLSX網拍訂單_10月A｜1,000 筆，故意弄亂 CSV咖啡店_銷售流水帳B｜一整年，9,197 筆 XLSX10月業績表C｜業務部 6 個人 TXT客戶會議逐字稿D｜設計工作室和客戶
上傳 Excel 檔前，先確認一個設定
Claude 要讀 Excel 檔、做出新的檔案，需要打開「設定（Settings）→ 功能（Capabilities）」裡的 Code execution and file creation。免費版預設是開的，如果你曾經關掉，記得再打開。

A｜網拍賣家：一句話把訂單表整理好

從賣場後台匯出來的訂單表，常常有重複的訂單、好幾種日期寫法、名字前後多打的空格。先不要急著叫它改，先問它看到什麼問題。

  1. 把 網拍訂單_10月.xlsx 拖進對話框，或按左下角的 ＋ 選檔案。
  2. 先問它這份表有什麼問題：
    這是我網拍賣場 10 月的訂單表。這份表你看得出什麼問題嗎？
    我實際測的時候，它找到 40 筆重複的訂單、5 種日期寫法、名字前後的空格、3 種 LINE Pay 寫法，還多提醒了「待出貨」的訂單太多。
  3. 再請它整理：
    好，幫我整理成乾淨的版本，取消的訂單另外放一個工作表。
    不到一分鐘，它會給你一個新的 Excel 檔，按檔案下載就好。你原本的資料它會另外留一份沒動。
  4. 一定要對筆數。1,000 筆扣掉 40 筆重複，應該剩 960 筆。示範檔整理完是 789 筆有效訂單加上 171 筆取消，合起來剛好 960。

公式不用背，請它寫

加一欄金額，用公式算，再用白話跟我解釋這個公式。

以後看到別人留下來、看不懂的公式，也可以貼給它問。公式跑出錯誤，就把畫面截圖給它。

同一招也能用在：補習班的學生名單、診所的預約紀錄，只要是從系統匯出來的表都可以。

B｜咖啡店：一年的流水帳變成會動的儀表板

不用先想好要畫哪一種圖，把你想知道的事情講出來就好。

這是我咖啡店過去一年的銷售流水帳。我想知道每個月賺多少、什麼賣最好、一天裡哪個時段最忙。幫我做成可以互動的儀表板。

我實際測大約一分半鐘就做好了：全年營收約 116 萬，拿鐵賣最好，早上 8 點到 10 點佔了三成營收。點一下月份，上面的數字就會換成那個月的。

儀表板做得再漂亮，數字錯了就沒用
挑一個月自己加一次，或直接問它「12 月的營收你是怎麼算的？」。示範檔 2025 年 12 月的營收是 103,925 元，你可以在原本的表篩選 12 月，選取金額欄，看右下角的加總是不是同一個數字。
Excel 裡的 Claude 外掛：Pro 以上才有，免費版不能用
Claude 有直接裝在 Excel、PowerPoint 裡的外掛，但要 Pro、Max、Team 或 Enterprise 方案才能用。
免費版這樣做：把檔案拖進對話 → 請 Claude 處理 → 下載新的檔案。多了上傳和下載兩步，結果是一樣的。

同一招也能用在：網拍可以看哪個商品該補貨，接案的工作室可以看哪一種案子最賺。

C｜上班族：業績表變成五頁簡報

跟它說三件事：要給誰看、要幾頁、最想講什麼。這就是 Day 0 教的：給背景、說目的、指定格式。

這是業務部 10 月的業績表，我下週要跟主管報告。幫我做成 5 頁的簡報檔，重點放在誰達標、誰沒達標、下個月該注意什麼。

這一步要等比較久，我實際測大約 4 分鐘。做好之後是一個 .pptx 檔，下載下來用 PowerPoint 或 Keynote 都能打開，每一頁還附了講稿。示範檔的結果：總業績 667 萬，達成率 97.4%，3 個人達標、3 個人沒達標。

報告前，請它扮演你的主管

請你扮演我的主管，列出他看完這份簡報最可能問的三個問題。

它會問很實際的問題，例如業績掉的人是人的問題還是客群的問題、流失的客戶原因是什麼。這些答案表裡沒有，報告前要先去問清楚。

PowerPoint 裡的外掛，也要付費版
和 Excel 一樣，Pro 以上才有。免費版就在對話裡請它做，再下載簡報檔。

同一招也能用在：開店的人寫給廠商的合作提案、接案的人給客戶的提案簡報、老師和講師上課用的講義。

D｜設計工作室：逐字稿變成會議記錄和信件

  1. 把 客戶會議逐字稿.txt 拖進對話，或直接把文字貼進去：
    這是今天和客戶開會的逐字稿。整理成三欄表格：決議、待辦事項、負責人和期限。
    十幾秒就好。示範檔裡，它還發現客戶說要回覆的 11/21 是星期六。
  2. 再請它寫信：
    根據這次會議寫兩封信：一封給客戶，確認今天談定的內容；一封給我主管，簡短回報進度和風險。
    寄出去之前一定要自己看一遍。人名、日期、金額，是最容易出錯的地方。

錄音檔可以直接丟嗎？暫時還不支援

我實際試過：錄音檔拖得進去，但 Claude 會直接告訴你它聽不到聲音。錄影檔也一樣，它看得到畫面，聽不到聲音。好消息是，它不會亂編一份假的會議記錄給你。

所以現在的做法是，先把聲音變成文字，再貼給 Claude。選你用的裝置：

iPhone：用「備忘錄」錄音

  1. 打開「備忘錄」，新增一則備忘錄，點 迴紋針 圖示，選「錄音」。
  2. 開會時開始錄，錄完按停止。
  3. 點開錄音，就看得到逐字稿。按「⋯」選「拷貝逐字稿」，貼給 Claude。

需要 iPhone 12 以上。Apple 官方列出支援「中文（台灣）」。這一段我是照 Apple 的官方說明寫的，還沒有每一款手機都實際測過。

Android 或電腦：Google 文件的「語音輸入」

  1. 用 Chrome 打開一份新的 Google 文件。
  2. 上方選單「工具」→「語音輸入」，語言選中文。
  3. 按麥克風，它會邊聽邊打字。開會時開著，結束後把文字全選，貼給 Claude。

語音輸入只能聽現場的聲音，不能上傳錄好的檔案。Word 網頁版的「轉錄」可以上傳錄音檔，但要有 Microsoft 365 訂閱。

預告：Claude Code
錄音檔直接變成會議記錄這件事，Claude Code 做得到。它是付費版的功能，Day 4 會教。

同一招也能用在：跟廠商談進貨、每週的部門例會。

今天的作業

  • 拿一份你自己工作上的表丟給 Claude。先問它：「這份表你看得出什麼問題嗎？」
  • 再請它整理，做成圖表或簡報。做完記得自己抽查數字。
  • 下次開會，試試看錄成文字，請它整理成會議記錄。
  • 過程中卡住了，就截圖問 Claude。
