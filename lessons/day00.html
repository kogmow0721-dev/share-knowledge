Day 0

開始用 AI 之前，你需要準備什麼

今天要做三件事：申請 Claude 和 ChatGPT 的帳號、裝好電腦版 App，再弄清楚到底要不要付錢。完全沒用過 AI 也沒關係，照著做就好。

影片即將上線

開始之前，先確認這四樣東西

  1. 一台電腦。 Mac：Claude 電腦版需要 macOS 13 以上，ChatGPT 電腦版需要 macOS 14 以上。Windows：10 或 11 都可以。
  2. 一個電子郵件信箱。有 Gmail 最方便，可以直接用 Google 帳號登入。
  3. 一支能收簡訊的手機。申請 Claude 時一定要驗證手機號碼。
  4. 年齡。Claude 要年滿 18 歲。ChatGPT 13 歲以上就能用，但未滿 18 歲要先得到家長同意。

申請 Claude 帳號

  1. 打開瀏覽器，在網址列輸入 claude.ai。
  2. 有 Gmail 的話按「Continue with Google」，再選你的 Google 帳號。想用其他信箱的話，輸入電子郵件後按「Continue with email」。
  3. 用電子郵件登入時，Claude 會寄一封標題是「Secure link to log in to Claude.ai」的信，按信裡的按鈕就能登入。收件匣找不到的話，去垃圾郵件匣看看。
  4. 第一次登入要驗證手機：輸入手機號碼，把收到的簡訊驗證碼填進去。
  5. 照畫面上的指示填完基本資料，就會進到聊天畫面。
手機驗證的兩個限制
網路電話的號碼不能用，例如 Google Voice。一個手機號碼最多只能驗證三個 Claude 帳號。

申請 ChatGPT 帳號

  1. 在網址列輸入 chatgpt.com，按右上角的「註冊」。
  2. 可以用 Google、Microsoft、Apple 帳號註冊，也可以用手機號碼或電子郵件。
第一次用哪一種方式註冊，之後就一直用同一種方式登入。
這次用 Google 註冊、下次改用電子郵件登入的話，可能會變成兩個不同的帳號，裡面的對話和訂閱不會合在一起。

安裝電腦版 App

網頁版現在就能用。裝電腦版的好處是之後打開比較方便。兩個系統的步驟不太一樣，選你的電腦：

Claude（macOS）

  1. 打開 claude.com/download，按「下載 macOS 版」。
  2. 打開下載的檔案，把 Claude 的圖示拖進「應用程式」資料夾。
  3. 從「應用程式」資料夾或啟動台打開 Claude，登入你的帳號。

ChatGPT（macOS）

  1. 打開 chatgpt.com/download。網頁會自動判斷你的 Mac 用的是哪一種晶片。
  2. 安裝好之後打開，登入你的帳號。ChatGPT 的 Mac 版需要 macOS 14 以上。

Claude（Windows）

  1. 打開 claude.com/download，按「下載 Windows 版」。也可以打開 Microsoft Store 搜尋 Claude 來安裝。
  2. 打開下載的安裝檔，照畫面上的指示安裝。
  3. 從開始功能表打開 Claude，登入你的帳號。

ChatGPT（Windows）

  1. ChatGPT 的 Windows 版只能從 Microsoft Store 安裝。打開 Microsoft Store，搜尋 ChatGPT。
  2. 搜尋結果有兩個：「ChatGPT」和「ChatGPT Classic」。請裝名字只有 ChatGPT 的那一個，它是新版。
  3. 按「取得」，裝好以後打開並登入。

手機版：先看開發者名稱

iPhone 到 App Store，Android 到 Google Play，搜尋 Claude 或 ChatGPT 就找得到。下載前一定要看開發者名稱：

  • Claude 的開發者是 Anthropic（App Store 上顯示為 Anthropic PBC）。
  • ChatGPT 的開發者是 OpenAI（App Store 上顯示為 OpenAI OpCo, LLC）。

開發者名稱不對的都是仿冒 App，不要下載。

要不要付錢？

方案價格（美元／月）內容
Claude 免費版$0聊天、上網搜尋、上傳檔案。每 5 小時和每週有使用上限。
Claude Pro$20（年繳每月 $17）用量更多，可以用更強的模型和 Claude Code。
ChatGPT 免費版$0聊天、上傳檔案，使用次數有限制。
ChatGPT Go$8訊息、上傳和畫圖的次數更多，可能會有廣告。
ChatGPT Plus$20更強的推理模型、專案功能。

我建議先用免費版至少一個禮拜。發現自己每天都在用，而且常常碰到上限，再考慮付費。

付費時盡量用電腦的網頁付款。Claude 有些方案在 iPhone App 裡買會比較貴，例如 Max 方案網頁上是 $100，App 裡是 $124.99。

今天的作業

  • 申請 Claude 和 ChatGPT 帳號，記得用同一種方式登入。
  • 安裝兩個電腦版 App。
  • 手機版有需要再裝，下載前確認開發者名稱。
